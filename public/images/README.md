# Dünya Kule görselleri

- `hero-mountain-day.jpg` / `hero-mountain-dusk.jpg`: dağlık baz istasyonu saha fotoğrafları (gündüz / alacakaranlık).
- Proje JPG’leri temsili saha görselleridir. Onaylı gerçek saha fotoğrafları geldiğinde `src/content/site.ts` yollarını güncelleyin.
- Eski SVG yer tutucular referans için tutulabilir; canlı site JPG kullanır.
- `hizmet-bolgesi.svg` ülke çizgilerini kamu malı [Natural Earth 1:110m Admin 0 Countries](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/) verisinden alır. Haritadaki işaret Tokat merkezini gösterir.
